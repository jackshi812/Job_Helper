## Trust Boundaries

OWASP ASVS Level 1; any HIGH or CRITICAL finding blocks schema push or completion.

| Boundary | Description |
|---|---|
| Approved local migration → hosted Supabase | Exact schema bytes cross a privileged non-interactive production boundary |
| User A browser → User B application/event/resume IDs | Guessed UUIDs must be blocked by RLS, FKs, and every RPC |
| Editable Tracker cells → database RPCs | Field, text, stage, date, URL, pin, and resume values are untrusted |
| Stored JD/notes/URL → rendered UI/navigation | Persisted values can still contain XSS or unsafe navigation payloads |
| Timeline events → current-stage projection | Concurrent corrections must not yield a forged/stale parent state |
| Dashboard feed → Tracker aggregate | A successful Mark Applied must not partially update or regain Active visibility |
| Verifier credentials/fixtures → evidence/cleanup | Secrets and disposable content must not leak or remain in production |
