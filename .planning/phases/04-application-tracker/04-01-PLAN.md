<threat_model>
## Trust Boundaries

OWASP ASVS Level 1; any HIGH or CRITICAL finding blocks completion.

| Boundary | Description |
|---|---|
| Dashboard browser → `mark_job_applied` | Untrusted user-job UUID enters a transaction that may snapshot shared job data and mutate owner state |
| Authenticated browser → tracker tables/RPCs | Application IDs, fields, stage values, dates, URLs, notes, and resume IDs are attacker-controlled |
| `applications` → `application_stage_events` | Parent/event ownership and derived current stage must remain consistent |
| `applications.resume_id` → private `resumes` | A guessed resume UUID must never create a cross-owner association |
| Stored snapshots → browser rendering | Provider HTML and external URLs remain untrusted after persistence |
| Legacy `user_jobs.applied_at` → tracker backfill | Existing owner history must migrate without loss, duplication, or re-parenting |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-04-01-01 | Information Disclosure / Elevation of Privilege | applications/events RLS | high | mitigate | Owner indexes and `auth.uid() = user_id` RLS on both tables; authenticated SELECT only; Plan 03 two-user negative probes |
| T-04-01-02 | Elevation of Privilege | definer RPCs | high | mitigate | Empty search path, fully-qualified objects, explicit owner lookup, exact execute ACLs, and RPC-specific cross-user tests |
| T-04-01-03 | Tampering | system snapshots/origin | high | mitigate | `mark_job_applied` snapshots server-side from an owned `user_jobs` row; no generic client writes to origin/source/snapshot columns |
| T-04-01-04 | Elevation of Privilege | resume association | high | mitigate | Composite `(resume_id,user_id)` FK plus RPC ownership validation and column-list SET NULL on owner resume deletion |
| T-04-01-05 | Spoofing / Tampering | manual/system URL and text inputs | high | mitigate | Bounded inputs, exact stage/origin allowlists, browser URL parser, database HTTPS/no-credentials checks, manual JD as text, system HTML sanitized at render |
| T-04-01-06 | Tampering | event/current-stage projection | high | mitigate | Atomic trigger-derived projection, no direct projection grant, deterministic ordering, final-event deletion guard |
| T-04-01-07 | Repudiation | legacy backfill/idempotent Mark Applied | medium | mitigate | Stable system uniqueness, immutable source provenance, migration parity tests, dated events, and idempotent RPC assertions |
| T-04-01-SC | Tampering | dependency supply chain | low | accept | No package installation; use only existing pinned React, Supabase, TanStack Query, DOMPurify, Tailwind, and Vitest dependencies |
</threat_model>
