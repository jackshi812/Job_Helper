## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Database → browser | Catalog, links, and status text are untrusted render data. |
| Browser → external careers site | A canonical third-party link opens a new browsing context. |
| Authenticated browser → catalog | Shared users may read evidence but cannot rewrite dispositions. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02.1-07 | Spoofing | Careers links | high | mitigate | Store and re-parse canonical HTTPS URLs; use explicit accessible labels and safe new-tab attributes. |
| T-02.1-08 | Tampering | Catalog disposition/source identity | high | mitigate | Strict checks, service-role-only writes, authenticated select-only RLS, fixed seed assertions, and the pinned Capital One source-key literal shared with Plan 06. |

| T-02.1-10 | Repudiation | Provider evidence | medium | mitigate | Persist provider, access method, evidence summary, disposition, and verification date. |
| T-02.1-SC | Tampering | Frontend supply chain | low | accept | Use existing React/Tailwind only and change no manifest or lockfile. |
</threat_model>
