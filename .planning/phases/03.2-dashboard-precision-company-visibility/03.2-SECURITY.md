## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| Browser → preferences | Authenticated input enters the own-row preferences upsert. | Nullable integer experience cap |
| Worker → database | Service-role scoring writes bounded filter outcomes. | Job eligibility and reason code |
| Provider description → parser | Untrusted posting text enters pure parsing logic. | Plain normalized text |
