<objective>Implement the Dashboard’s session-only company and score-tier precision controls and preserve detail-only match reasons.</objective>

## Decision coverage
- D-01: narrowed checked companies provide the optional preferred-companies-only filter mode, never ranking or pinning.
- D-02: company/tier state is in-memory only and never changes scoring, persistence, polling, or future ingestion.
- D-03: all companies start checked; unchecked hides current rows; Reset restores the checked draft.
- D-04: options/search use only truthful names from the authorized current feed; arbitrary companies are not accepted.
- D-05: controls are Dashboard-only in the inline expandable panel above results.
- D-06: the panel includes search, checkbox list, Reset, and Show results.
- D-12: Strong/Good/Weak are all selected by default and precision is limited to company/tier filters.
- D-13: company and tier filters compose with AND semantics.
- D-14: only Dashboard uses the remaining full browser width.
- D-15: Match reason leaves the list table but remains on JobDetail.
- D-16: Location uses the existing jobs.location field.
