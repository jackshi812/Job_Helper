## Trust Boundaries

| Boundary | Description |
|---|---|
| Browser form → authenticated RPC | Untrusted rubric/preferences enter server-authoritative validation. |
| Supabase rows → React rendering | RLS-scoped stored tier/evidence/job text reaches UI. |
| Browser retry → run state | Duplicate/stale clicks must not create unauthorized work. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-03.4-12 | Tampering | rubric editor | high | mitigate | Mirror closed integer/total/order/threshold bounds, retain server authority, and test zero remote calls on invalid input. |
| T-03.4-13 | Information disclosure | feed/detail projections | high | mitigate | Select only deterministic allowlisted fields under existing RLS; remove AI/resume evidence and render bounded evidence as text. |
| T-03.4-14 | Spoofing / Repudiation | retry | medium | mitigate | Use authenticated server state/retryability, native disabled pending state, and never infer/reset retry count in React. |
| T-03.4-15 | Tampering | tier/filter display | medium | mitigate | Consume stored tier; never recompute thresholds in browser; cover all/none/partial filter semantics. |
| T-03.4-SC | Tampering | package supply chain | high | mitigate | Install no packages and preserve the existing manual Tailwind/native control system. |
</threat_model>
