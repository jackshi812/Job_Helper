## Decisions Made

- Used the stored deterministic tier everywhere; the browser neither derives tiers from score nor gives pending rows an `Unranked` or synthetic `Weak` presentation.
- Kept ranking-state polling separate from the feed query so building and failure states cannot blank or disable the prior complete snapshot.
- Triggered one exact feed refetch only when the active revision advances, followed by the polite `Rankings updated.` announcement.
- Rendered stored breakdown evidence as plain text in a semantic table and retained DOMPurify for the independent job description boundary.
