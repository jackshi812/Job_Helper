## Decisions Made

- Existing work always drains before recency/new-job maintenance can create
  more work.
- A fully staged orphan is recovered only by scanning bounded building state
  and calling the existing transactional finalizer; worker code never writes
  active publication state directly.
- Current-open completeness is the release boundary. Completed active-revision
  items for jobs that subsequently close are permitted only when every
  ownership, revision, user-job, and terminal-status invariant remains valid.
- Signed-in release evidence was kept read-only. Preference save, Retry,
  mark-seen, Apply, Dismiss/Restore, fixture creation, failure injection, and
  time manipulation remained excluded.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Repaired historical-closure verifier false negative**

- **Found during:** Task 3 convergence validation
- **Issue:** A job closed after capture, so a correct completed active snapshot
  contained one historical row beyond the current-open universe.
- **Fix:** Made current-open jobs the exact coverage gate and permitted only
  valid completed closed history.
- **Files modified:** verifier, verifier tests, preflight.
- **Verification:** Current-open negative cases and post-release verification
  pass.
- **Committed in:** `91955ab`

**2. [Rule 1 - Bug] Prevented recency work from outrunning queue drain**

- **Found during:** Task 3 production convergence
- **Issue:** Maintenance ran before each small claim and could enqueue a new
  full snapshot before older owner work completed.
- **Fix:** Claim first, maintain at most once after an empty claim, drain
  repeated 25-item batches with concurrency 25, and bound an invocation to
  5,000 items/45 seconds.
- **Files modified:** worker, verifier, tests, preflight.
- **Verification:** Focused liveness and full suites pass; queue converged.
- **Committed in:** `6b8e1b5`

**3. [Rule 1 - Bug] Recovered terminal staged runs after hard invocation death**

- **Found during:** Task 3 finalization
- **Issue:** One invocation died after all terminal staging but before its
  finalizer call; later claims could not rediscover the fully staged run.
- **Fix:** On an empty initial claim, scan at most 25 building run IDs and call
  only the existing atomic finalizer before maintenance.
- **Files modified:** worker, verifier, tests, preflight.
- **Verification:** 19/19 verifier tests, 631/631 web tests, bounded production
  recovery, 2/2 complete owners, and zero queue failures.
- **Committed in:** `452b6a3`
