# Phase 03.3 — Security

> ASVS Level 1 verification of the threat registers declared in Plans 01–04,
> evaluated against the repaired current production release.

---

## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| Authenticated browser → preference RPC | Owner-controlled text arrays enter an RLS-owned preference and ranking revision | Titles, locations, keyword arrays, rubric, and thresholds |
| Preference row → privileged ranking worker | Validated owner preferences cross into a service-role worker | Captured ranking inputs and bounded job data |
| Provider job data → eligibility/ranking | Untrusted external titles and descriptions enter normalization and filtering | Public job content |
| RLS-scoped feed → Dashboard controls | Client company/tier controls may narrow, but never widen, authorized rows | Owner-visible ranked jobs |
| Local release → Supabase/Cloudflare | Approved migrations, function source, and web assets become production state | Schema, worker, and browser application |
