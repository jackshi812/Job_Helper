## Title Exclusions

### Seed behavior

| Option | Description | Selected |
|--------|-------------|----------|
| Removable seeded defaults | Seed `president` and `PhD` for existing and new users, but allow either to be removed. | ✓ |
| Mandatory defaults | Always enforce both values and prevent removal. | |
| Inactive suggestions | Display the values but require manual activation. | |

**User's choice:** Removable seeded defaults.

### PhD variants

| Option | Description | Selected |
|--------|-------------|----------|
| Punctuation and spacing variants | Match `PhD`, `Ph.D.`, and `Ph D` case-insensitively. | ✓ |
| Exact normalized word | Match only `PhD`. | |
| Broader concepts | Also match `doctorate` and `doctoral`. | |

**User's choice:** Match punctuation and spacing variants without broader synonym expansion.

### President scope

| Option | Description | Selected |
|--------|-------------|----------|
| Any whole-word occurrence | Match President, Vice President, Senior Vice President, and other titles containing the whole word. | ✓ |
| Exact title only | Match only a title equal to President. | |
| Limited variants | Match President and Vice President but not longer variants. | |

**User's choice:** Any whole-word occurrence.

### Empty list

| Option | Description | Selected |
|--------|-------------|----------|
| Allow empty | Save no title exclusions and exclude no titles. | ✓ |
| Restore defaults | Re-add `president` and `PhD` when the list is empty. | |
| Require one | Block saving unless at least one value remains. | |

**User's choice:** Allow an empty list.
