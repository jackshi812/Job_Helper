- **Issue:** Workday returned the authoritative total on page zero and `total=0` on structurally valid, non-empty later pages, causing the adapter to fail closed.
- **Fix:** Kept the page-zero total authoritative and accepted zero only on valid non-empty later pages.
- **Files modified:** `supabase/functions/_shared/adapters/workday.ts`, `web/tests/workday-connector.integration.test.ts`
- **Verification:** RED/GREEN integration regression plus complete 705-row observation reconciliation.

- **Found during:** Task 3 live Fidelity verification

- **Fix:** Counted tombstones for completeness while excluding them from materialized jobs and retaining strict row/schema checks.
- **Files modified:** `supabase/functions/_shared/adapters/workday.ts`, `web/tests/workday-connector.integration.test.ts`
- **Verification:** RED/GREEN regression and clean 705/705 observations.
