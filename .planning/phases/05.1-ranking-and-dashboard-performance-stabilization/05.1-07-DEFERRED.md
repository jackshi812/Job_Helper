<interfaces>
Current publication authority is `deterministic_ranking_state.active_run_id`;
current work and retry availability are anchored by `building_run_id`, state
status, and `retry_available`. Retry copies item inputs from the failed source
run and records `retry_of_run_id`; retention must therefore protect the full
connected retry lineage of any active/building/retry-available run. The latest
`completed` run per `(user_id, run_kind)` is also protected.

`deterministic_ranking_items` contains the full payload (job/user_job links,
scores, breakdown, filter detail, and resume references). The new summary table
may contain only run identity/reason/revision/status/timestamps/error code and
aggregate item/attempt counts—never captured preferences, job/user_job/resume
IDs, scores, breakdowns, or filter details.
</interfaces>
