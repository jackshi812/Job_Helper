## Accomplishments

- Dismiss now removes its target in the initiating turn before query cancellation, scopes pending state to the exact ID, and filters pending/successful IDs from late feed responses (D-11, D-17).

## Decisions Made

- Used component-session exclusion rather than persistence because the RPC remains the durable authority and the exclusion only protects the current browser session from stale in-flight data.
- Kept Mark Applied's whole-snapshot behavior untouched while introducing a dismissal-only context and rollback path.
- Represented refill retry as a discriminated scope so the existing Retry button repeats the correct all-jobs cursor backfill or watchlist refetch.
