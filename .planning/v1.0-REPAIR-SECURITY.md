# v1.0 Integration Repair Security Review

## Security Boundary

The monitored-company/source catalog and raw provider job pool are shared
system data for the two invited authenticated accounts. Anonymous access is
denied. Preferences, resumes/extracts, ranking state/runs/items, dismissals,
applications/events, and per-user usage accounting remain owner-scoped.

## Threat Review

| Threat | Control | Result |
|---|---|---|
| Anonymous or unauthenticated RPC use | All new functions reject a null `auth.uid()`; `PUBLIC` and `anon` execution are revoked | closed |
| Delete another user's data | `delete_my_data()` derives one immutable `owner_id` from `auth.uid()` and every delete/update predicate uses it | closed |
| Definer search-path injection | The deletion RPC is `security definer` with `set search_path = ''` and fully qualified relations | closed |
| Delete shared catalog or account identity | The deletion body excludes `companies`, `jobs`, `profiles`, and `auth.users`; source decision and UI copy state what remains | closed |
| Leave newer personal records behind | The final migration explicitly covers applications/events, dismissals, ranking state/items/runs, usage, extracts, resumes, preferences, and user jobs | closed |
| Partial database cleanup | The RPC executes transactionally; a relation/FK failure rolls back its database changes | closed |
| Cursor reuse across Watchlist/All Jobs | Source scope is normalized into the client query signature and cache key; the base RPC validates the signature on every continuation | closed |
| Misleading empty Watchlist page | Source and tracker membership filters run while scanning base keyset pages, before the outward `p_limit`; `has_more` is derived from accepted rows | closed |
| Invalid or null source scope | Both versioned RPCs accept exactly `watchlist` or `all` and reject null/other values | closed |
| Rolling-release outage | Migration 0059 adds versioned RPCs and preserves the old functions for the currently hosted client; the web switches only after migration deployment | closed |
