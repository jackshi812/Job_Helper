## Trust Boundaries

Security baseline: OWASP ASVS Level 1.

| Boundary | Description |
|---|---|
| Immutable manifest → activation controller | No privileged dependency may be constructed before exact approval |
| Live Higher evidence → service-role terminal | External data may grant authority or a precise Unsupported result only |
| Scheduler state → observation/poll acceptance | Exactly three accepted windows and a later natural poll must be observed, never manufactured |
| Privileged verifier → production data | Service-role access must be secret, finite, snapshot-checked, and cleanup-verified on every exit |
| Hosted evidence → owner UAT | Browser acceptance must refer to the same immutable release and real row |
