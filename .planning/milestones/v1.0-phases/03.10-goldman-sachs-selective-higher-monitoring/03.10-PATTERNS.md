  const labelTokens = categoryTokens(providerCategoryLabel)

## Shared Patterns

### Authentication and authorization

**Sources:** `connectors.ts` lines 93-113, migration 0045 lines 246-251 and
402-407.

- Re-resolve literal source keys to frozen registry objects.
- Reject caller-selected host, path, operation, filter, population, or Oracle
  coordinate before network access.
- Keep terminal, observation, and claim RPCs `security definer` with
  `search_path=''`.
- Revoke from `public`, `anon`, and `authenticated`; grant only `service_role`.

### Error handling

**Source:** `goldman-higher.ts` lines 137-151, 166-235, and 534-536.

- Convert provider failures into bounded snake-case codes.
- Mark failures/partials closure-ineligible.
- Retain any proven partial rows only as partial evidence; never activate or close.
- Do not log or persist raw provider payloads, credentials, or unbounded errors.

### Completeness and no false closure

**Sources:** `lifecycle.ts` lines 49-57 and 112-124; Phase 03.9 selective adapter
pattern.

`credibleForClosure=true` means the selected observation is internally complete;
it does not override `allowMissingClosure=false`. For every Goldman outcome:

```typescript
allowMissingClosure: false
```

This allows a healthy observation/heartbeat while permanently denying
missing-job closure. No migration or poller branch may close Goldman on age or
selective absence.

### Rolling-window feed expiry

The adapter validates admission at its injected poll wall clock. The SQL feed
function evaluates current Active visibility at database server time. These are
deliberately separate checks:

1. Adapter excludes missing, malformed, future, or older-than-168-hour roles and
   marks the observation incomplete when freshness is untrustworthy.
2. Persistence keeps accepted jobs provider-open.
3. `dashboard_feed_page` excludes aged Goldman rows only for Active lifecycle.
4. Applied/dismissed history remains available.

### Validation

- Exact enums: `EARLY_CAREER`, `PROFESSIONAL`, `GS_EARLY_CAREER`,
  `GS_MID_CAREER`.
- Exact list/detail equality: role ID, source ID, title, selected U.S. location,
  category field/normalized label/term, and posting instant.
- Exact status/apply evidence: `POSTED`, provider external status `POSTED`,
  `ORACLE`, `applyActive=true`, `applyInExternalSource=true`.
- Exact Oracle Apply path and numeric source-ID binding.
- Bounded every page, byte count, item count, detail request, concurrency, request
  time, and total invocation time.

### Testing

Use table-driven positive/negative fixtures, injected clocks/fetch/command runners,
and source-text migration assertions. Every drift fixture must assert:

- bounded warning;
- incomplete/unknown or partial result;
- `credibleForClosure=false`;
- `allowMissingClosure=false`;
- no unproven persisted row;
- no network call when identity resolution fails;
- no production command when approval differs by any byte.
