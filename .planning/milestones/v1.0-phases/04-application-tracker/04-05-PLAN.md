`markJobApplied(userJobId)` returns the application UUID from the atomic
`mark_job_applied` RPC. Dashboard invalidates:
- the exact Active feed key
- `['tracker-applications']`
- `['tracker-application', applicationId]`
- `['dashboard-applied-applications']`

Show applied consumes `listDashboardAppliedApplications` and never coerces its
snapshot rows into `FeedRow`. Its exact return type is
`DashboardAppliedApplication[]`, with
`{ applicationId, company, title, location, applyUrl, appliedOn,
currentStage, currentStageDate }` parsed from the identically ordered
`dashboard_applied_applications() returns table(application_id uuid, company text, title text, location text, apply_url text, applied_on date, current_stage text, current_stage_date date)` contract. `applyUrl` is nullable after the shared
HTTPS/no-credentials guard. `appliedOn` is database-owned and comes from the
earliest Applied event under
`ORDER BY occurred_on ASC, created_at ASC, id ASC LIMIT 1`;
Dashboard must not derive it from current stage/date or a live job row.
The Tracker target is
`/tracker?application={applicationId}` and is resolved only against the
authenticated user's loaded tracker rows.
</interfaces>

## Trust Boundaries

OWASP ASVS Level 1; any HIGH or CRITICAL finding blocks completion.

| Boundary | Description |
|---|---|
| Dashboard row → atomic Mark Applied RPC | Untrusted user-job ID must never snapshot or mutate another owner's data |
| Tracker-backed projection → Dashboard | Historical snapshots/stages must remain owner-filtered and safe to render/navigate |
| Dashboard query parameter → Tracker focus | An attacker-controlled application UUID must not reveal ownership/existence |
| Optimistic Active cache → durable lifecycle | Client rollback/invalidation must not create a second source of truth |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-04-05-02 | Information Disclosure | Show applied | high | mitigate | Owner-filtered tracker projection, system-origin-only rows, no live cross-join |
| T-04-05-03 | Information Disclosure | Tracker focus parameter | high | mitigate | Validate shape, resolve only against loaded owned rows, identical behavior for missing/non-owned IDs |
