## Trust Boundaries

| Boundary | Description |
|---|---|
| UI interaction → authenticated lifecycle mutation | Apply navigation and lifecycle writes must not be conflated. |
| React Query cache → persisted truth | Optimistic state must roll back exactly on write failure. |
| Page cursor → rendered queue | Appended pages/backfill must not duplicate, reorder, or hide loaded truth. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-03.6-03-01 | Tampering | optimistic lifecycle cache | medium | mitigate | Cancel/snapshot exact query pages, bind mutations by user_job id, exact rollback, invalidate affected lifecycle keys. |
| T-03.6-03-02 | Spoofing | Apply vs Applied semantics | medium | mitigate | Separate link/button paths and tests proving navigation cannot invoke lifecycle mutation. |
| T-03.6-03-03 | Tampering | cursor/page merge | medium | mitigate | Complete query keys, strict feed cursor validation, ID dedupe, stable prior-page order, duplicate-activation lock. |
| T-03.6-03-04 | Denial of Service | Load more/backfill | low | accept | One in-flight request per action, fixed 200/one-row limits, bounded retry; impact is limited to current user's view. |
| T-03.6-03-05 | Information Disclosure | UI errors/live regions | low | accept | Bounded fixed copy contains no provider payload, tokens, or cross-user identifiers. |
| T-03.6-03-SC | Tampering | dependency supply chain | low | accept | No UI/icon package install; existing React/TanStack/Tailwind primitives only. |
</threat_model>
