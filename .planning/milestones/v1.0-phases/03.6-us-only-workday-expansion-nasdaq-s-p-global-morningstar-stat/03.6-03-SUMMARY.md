## Decisions Made

- Used the complete server query as the React Query identity so lifecycle and filters apply before the 200-row database limit.
- Preserved the current infinite cache during successful moves, invalidated only inactive lifecycle caches immediately, and merged one same-query backfill row to avoid full-table loading or scroll jumps.
- Serialized lifecycle mutations and bound the temporary Undo notice to one settled Mark Applied row so concurrent actions cannot corrupt snapshots or redirect Undo.
- Treated backfill as best effort after the lifecycle commit: a failed backfill does not undo persisted user intent.
