# Phase 03.6 — Security

## Trust Boundaries

| Boundary | Description | Data Crossing |
|---|---|---|
| Untrusted Workday identity and CXS payloads → admitted source | Exact tuple admission and external facet/list/detail evidence | Public provider identifiers and job metadata |
| Authenticated browser → lifecycle data | User-controlled filters, cursors, IDs, and lifecycle writes | Own-user lifecycle state |
| Per-user `user_jobs` → shared `jobs` | Reversible user state must not mutate shared job truth | User timestamps versus shared snapshots |
| Approved local release → Supabase and Cloudflare | Production changes require exact source, target, and artifact identity | Schema/function/web bytes and metadata |
| Disposable verifier → production | Bounded fixtures must remain isolated and removable | Deterministic synthetic jobs and users |
| Immutable deployment → owner UAT | Human observations must refer to the exact hosted release | Deployment identity and interaction results |
