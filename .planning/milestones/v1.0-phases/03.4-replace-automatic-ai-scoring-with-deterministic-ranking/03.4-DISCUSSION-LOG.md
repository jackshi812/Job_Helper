## Ranking Formula

The owner rejected generic fixed/count/band choices and supplied a custom additive rubric.

| Decision | Alternatives considered | Selected |
|---|---|---|
| Score shape | Generic fixed formula, match count, priority bands, custom | Custom 100-point additive rubric ✓ |
| Experience | +20 points, hard filter with score out of 80, hard filter with normalization | +20 points ✓ |
| Title semantics | Strict phrase/weak concepts, strict all words/weak any word, user aliases | Strict phrase/weak concepts ✓ |
| Adjustability | Every value, category maximums only, preference values only | Every point value ✓ |

**User's choice:** Defaults are strict title 30, weak title 20, location 10, last-day recency 10, watchlist source 10, experience 20, and include keywords 3/5/10/15/20. Every point value is editable with total/ordering validation.

---

## Hard Filters vs Points

| Decision | Alternatives considered | Selected |
|---|---|---|
| No title match | Hide, keep at zero title points, keep only above total threshold | Hide ✓ |
| Ambiguous location | Require positive US evidence, allow Remote/blank, allow blank only | Allow Remote/blank ✓ |
| Experience visibility | Soft score, hard filter, partial score | Soft score ✓ |
| Missing years | 0, 20, or 10 points | 0 points ✓ |

**User's choice:** Explicitly foreign jobs and jobs without any target-title match are hidden. Location keywords and experience are soft points. Existing title/general exclusions remain hard.

## Tiers and Old AI Scores

| Decision | Alternatives considered | Selected |
|---|---|---|
| Default thresholds | Current 75/50, raised 80/60, custom, no tiers | Current 75/50 ✓ |
| Threshold adjustment | Editable, fixed, presets | Editable ✓ |
| AI-score transition | Replace all before switch, clear immediately, gradual, dual-mode | Replace all before switch ✓ |
| AI reasons/gaps | Deterministic replacement, delete, historical label, reasons only | Deterministic replacement ✓ |

**User's choice:** No mixed scoring sources. Historical AI results become non-displayed migration evidence, while deterministic score/tier and point evidence own the active UI.

## Updates and Explanations

| Decision | Alternatives considered | Selected |
|---|---|---|
| Preference/rubric recalculation | Atomic switch, progressive rows, blocking save, hidden Dashboard | Atomic switch ✓ |
| New jobs | After score, Unranked first, Weak first | After score ✓ |
| Explanation placement | Detail rubric, Dashboard popover, Dashboard column, both | Detail rubric ✓ |

**User's choice:** Recalculation never makes jobs disappear or publishes mixed versions. The previous complete snapshot remains until a complete replacement is ready; failures retain it with Retry.
