## ASVS Level

OWASP ASVS Level 1. Any HIGH or CRITICAL finding blocks schema push or completion.

## Trust Boundaries

| Boundary | Description |
|---|---|
| Authenticated browser → security-definer RPCs | Untrusted own-user preferences request privileged validation/run creation. |
| Service worker → run items/user_jobs | A cron-secret-protected service client stages and promotes protected result fields. |
| Local migration → hosted PostgreSQL | An approved CLI command creates production objects and privileges. |
| Shared jobs/resumes → per-user runs | Shared job data and private resume routing must not cross owner boundaries. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-03.4-06 | Elevation of privilege | authenticated ranking RPCs | critical | mitigate | Derive owner from `auth.uid()`, use empty search path/schema-qualified SQL, closed validation, explicit revoke/grant, and own-row RLS tests. |
| T-03.4-07 | Tampering | active snapshot promotion | critical | mitigate | Lock state/run, verify revision and complete current universe, seed missing work, then promote all fields/state in one transaction. |
| T-03.4-08 | Information disclosure | run/items/evidence | high | mitigate | Own-row state/run reads only, no authenticated item access, bounded sanitized evidence, and no resume/job-description content in logs/evidence docs. |
| T-03.4-09 | Denial of service | rubric/items/retry | high | mitigate | Enforce integer/JSON/cardinality/byte bounds, bounded claims/concurrency/attempts, one retry, and fail closed without active-data mutation. |
| T-03.4-10 | Spoofing | score-tick | high | mitigate | Preserve cron-secret authorization before service-role work and deploy only in Plan 04 after exact-source approval. |
| T-03.4-11 | Repudiation / Tampering | production schema push | critical | mitigate | Require checksum-bound owner checkpoint, sole-pending-migration inventory, exact `supabase db push`, and remote parity/RLS/grant evidence. |
| T-03.4-21 | Elevation of privilege / Denial of service | initial-backfill initializer | critical | mitigate | Own it by postgres, grant only service_role, bound each call to 25 owners, enforce one initial run per owner, return counts only, and require the Plan 04 exact-SHA approval before invocation. |
| T-03.4-SC | Tampering | package supply chain | high | mitigate | Install no package; use the existing pinned Supabase CLI and lockfile. |
