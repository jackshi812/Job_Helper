# Phase 03.4 — Security

## Trust Boundaries

| Boundary | Description | Data Crossing |
|---|---|---|
| Browser ↔ Supabase | Authenticated preferences, feed projections, ranking state, and Retry RPC | Own-user settings and bounded deterministic results |
| Scheduler ↔ score-tick | Cron-secret-authenticated deterministic worker invocation | Work IDs and bounded deterministic facts |
| Worker ↔ database | Service-role claim, stage, recovery, maintenance, and finalize RPCs | Ranking protocol state; no provider prompt/resume body |
| Release tooling ↔ Supabase/Cloudflare/GitHub | Checksum-bound schema, function, and web release | Artifact bytes, metadata, hashes, counts |
| Evidence ↔ repository | Sanitized rollout, convergence, cost, and UAT records | Hashes/counts/status only; no credentials or user content |
