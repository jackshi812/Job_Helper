## Failure and Recovery

The removal request has no bounded client-side timeout or cancellation path. `removeCompany` awaits the Supabase delete request without a deadline; `ConfirmDialog` keeps `confirming=true` until that promise settles, disables both buttons, and disables Escape while confirming. A network request that stays pending therefore provides neither an in-dialog error nor a usable cancel/retry path.

Recovery was non-destructive: the user reloaded while still offline to abort the request, restored **No throttling**, reloaded again, and confirmed Curi Capital was still present.
