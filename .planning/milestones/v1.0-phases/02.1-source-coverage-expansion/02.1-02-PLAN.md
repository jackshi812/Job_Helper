## Review disposition

Rewriting `watchlist.test.ts` away from the browser-insert mock is intentional contract migration, not duplicate coverage: the old assertion would preserve the authorization flaw. Gateway JWT validation is retained only as defense-in-depth; `auth.getUser` plus the real `authenticated` user/role check is the privileged-write gate. The migration drops orphaned insert/update policies, and structural tests replace the former exact-string grep so harmless SQL formatting cannot fail the design gate. Migration 0012 necessarily invalidates authenticated fixture writes in `scripts/verify-watchlist.ts` and `scripts/verify-pipeline.ts`; Plan 07 is the explicit owner that updates both scripts before the only linked schema push and reruns both as hosted regression proof. Plan 01's temporary three-provider dispatch is replaced here in the immediately dependent wave so no new provider can ever rely on the staging branch.
