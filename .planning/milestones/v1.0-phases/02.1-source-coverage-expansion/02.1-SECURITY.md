|----------|-------------|---------------|

| Signed-in browser → verification/API | User identity crosses JWT, handler auth, registry, and RLS boundaries | Owner-visible catalog and verification requests |

| Catalog/database → Watchlist UI | Stored URLs, source identity, health, and removal state become user-visible | Career links, monitoring status, and owner rows |
| Approved source → hosted release | Exact Git, Supabase, and Cloudflare identities become production | Migrations, functions, and web assets |
