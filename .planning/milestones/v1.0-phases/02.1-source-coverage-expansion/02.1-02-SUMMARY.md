## Decisions Made

- Kept the Edge gateway JWT check enabled but made `auth.getUser(token)` plus `role === 'authenticated'` the privileged-write authorization decision.
- Created service-role clients only after live provider verification, so invalid users and failed boards cannot reach privileged construction or mutation.
- Kept existing Greenhouse, Lever, and Ashby rows Active during backfill; future connectors default to Experimental and cannot enter either SQL claims or application dispatch.
- Returned HTTP 409 with a stable already-watched payload and taught the browser client to surface bounded function-error response messages without restoring direct table writes.
